# ACM Solutions

个人 C++ 算法训练与学习记录。

本仓库用于整理算法练习代码、训练赛记录和 Markdown 学习笔记，记录解题思路、实现过程以及遇到的问题。

## 📚 Contents

主要包括：

- **Algorithm Practice**：C++ 算法练习与题目代码
- **Contest Solutions**：训练赛与算法竞赛代码
- **Algorithm Notes**：算法原理、题解和学习笔记
- **Templates**：经过验证的常用算法模板

## 📁 Repository Structure

随着代码逐步积累，计划按照以下结构整理：

- `topics/`：按照算法知识点分类
- `contests/`：按照比赛分类
- `templates/`：经过验证的算法模板

## 📝 Notes

- 主要使用 C++ 进行算法练习。
- 学习笔记使用 Markdown 编写。
- 代码仅代表个人学习和实践记录，不保证全部通过在线评测。
- 对于尚未验证的代码，不标记为 Accepted。
- 引用他人代码或思路时注明来源。
